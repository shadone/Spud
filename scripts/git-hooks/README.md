# Git hooks

## pre-commit

Runs SwiftFormat in lint mode (`mint run swiftformat --lint .`) and fails the
commit if anything is unformatted. Format with `mint run swiftformat <paths>`
before staging.

There is no Xcode-project sort step: `Spud.xcodeproj` is generated by XcodeGen
and gitignored, so there is no tracked `project.pbxproj` to sort. The project is
defined in `project.yml`; regenerate with `make project`.

Install:

```sh
ln -sf ../../scripts/git-hooks/pre-commit .git/hooks/pre-commit
```
